# AI-Content-Summarizer
An AI-powered content summarizer built with LangChain, Groq GPT-OSS 20B, and Streamlit. Summarize YouTube videos and website articles using natural language processing and large language models

An AI-powered application that summarizes YouTube videos and website articles using **LangChain, Groq GPT-OSS 20B, and Streamlit**.

## ✨ Features
- YouTube video transcript summarization
- Website article summarization
- Groq GPT-OSS 20B integration
- LangChain summarization pipeline
- Interactive Streamlit interface
- Custom dark-themed responsive UI

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- Groq API
- GPT-OSS 20B
- YouTube Transcript API

## 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd AI-Content-Summarizer
python -m venv .venv
```

Activate environment:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
streamlit run app.py
```

## 🔑 Configuration

Get your API key from [Groq Console](https://console.groq.com/keys) and enter it in the application sidebar.
